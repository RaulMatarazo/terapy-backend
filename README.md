# 🐎 Minha Aplicação com Delphi Horse

Este é um projeto backend desenvolvido em **Delphi** utilizando o **framework Horse**, com foco em performance, simplicidade e estrutura clara de rotas e middlewares.

## 🚀 Tecnologias Utilizadas

- Delphi
- Horse (https://github.com/HashLoad/horse)
- DataSet Serialize
## ⚙️ Funcionalidades

- ✅ API RESTful
- ✅ Integração com frontend (ex: React)
